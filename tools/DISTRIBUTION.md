# ZhIME Windows x64

将整个目录解压到打算长期保留的位置，可放在 E 盘。双击 `Install-ZhIME.cmd`，接受 Windows 管理员确认。升级后关闭并重开正在输入的应用。按 Win+空格选择 ZhIME 自研全拼，即可自动启动后台。

首次切入先加载词库，再在后台加载模型。词库就绪后即可选词，模型就绪后开放重排和联想。切换到其他输入法后，后台在约 3 秒无焦点确认时退出并释放 CUDA 上下文。切回后自动启动。

GPU 重排和联想需要能运行 CUDA 12.4 的 NVIDIA 驱动。缺少可用 CUDA 时，词典候选可用。日志位于 `runtime/automatic-engine.log`。双击 `Uninstall-ZhIME.cmd` 注销，关闭应用后可删除解压目录。

包内包含 CPython 3.10.11 和 PyTorch 2.6.0 CUDA 12.4，以及对应第三方许可。Python 3.10.11 为兼容本模型依赖采用的旧运行时。此包适用于组内和本机复现。对外发布权重前需确认训练数据及权重的再分发许可。
